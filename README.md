# Jeux de Conducteur Logiphar

## Présentation

**Jeux de Conducteur Logiphar** est une application web destinée à proposer une expérience interactive autour du métier de conducteur et de la livraison de colis.

Le projet a été développé dans le cadre de **Logiphar** afin de créer une expérience simple, accessible et ludique permettant de mettre en scène différentes situations liées à la conduite et à la livraison.

Le projet comporte actuellement deux versions :

- **Version A**
- **Version B**

Les deux versions sont accessibles directement depuis un navigateur web grâce à leur déploiement sur Netlify.

---

## Objectif du projet

L'objectif de **Jeux de Conducteur Logiphar** est de créer une expérience interactive autour des activités d'un conducteur chargé de transporter et de livrer des colis.

Le projet cherche notamment à mettre en avant :

- La conduite
- La livraison
- La gestion d'une course
- Le transport de colis
- Les différentes étapes d'une mission
- La prise de décision du conducteur
- Une expérience interactive accessible depuis un navigateur

---

## Fonctionnement

Le joueur accède au jeu depuis un navigateur web.

Le principe général consiste à :

1. Accéder au jeu.
2. Commencer une course.
3. Effectuer les différentes actions demandées.
4. Suivre le déroulement de la mission.
5. Atteindre les objectifs de la course.
6. Terminer la livraison.

L'expérience est conçue pour être simple à utiliser et directement accessible sans installation complexe.
